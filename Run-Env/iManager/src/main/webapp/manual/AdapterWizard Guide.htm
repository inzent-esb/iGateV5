2. 어댑터 위저드

어댑터 위저드 각 항목들은 확장성을 고려하여 Property 정보로 관리한다.

어댑터 위저드 화면의 각 항목의 목록 및 자동 선택 항목들은 어댑터 위저드 관련 Property 정보에 의해서 동작한다.

어댑터 타입 > 메시지 타입 > 요청 방향 순서로 선택하는 방식은 어댑터 위저드 관련 Property 정보의 종속 관계에 의한 처리를 위함이다.

 

 

 어댑터 위저드 화면에서 사용하는 Property 정보들을 각 항목 별로 확인한다.

 Custom에 의해서 설정값 (Activity, Operation, 기본 값) 등을 변경해야 할 경우 참고한다.

2.2 어댑터 위저드 어댑터 관련 정보

어댑터 위저드 화면에서 어댑터 정보 항목 중 목록이 표현되기 위한 어댑터 위저드 관련 Property 정보를 확인한다.

어댑터 타입, 메시지 타입, 요청 방향, 거래 방식, Property 정보는 입력 순서에 따라서 각 목록이 달라진다.

 

 

 

 

 

어댑터 위저드 화면의 항목 상위 선택에 따른 하위 목록이 종속적으로 Property 정보에 의해서 처리한다.

어댑터 타입 목록, 요청 방향 목록, 거래 방식 목록 및 케이스 별로 자동 선택되는 설정 정보(Telegram Handler. Charset, 거래 방식 선택)에 관한 Property 정보를 확인한다.

 

■ 참고

{항목 + Property Key} 조합하여 하위 연결된 정보를 추출하는데 이용된다.

 

 ex 1) 어댑터 타입(♣) 선택된 Property Key(★) → {♣★} 

       ▷ 어댑터 타입 "대외 온라인" 선택 시 → Online.External

       ▷ 어댑터 타입 "File" 선택 시 → File

 ex 2) 거래 방식(◆) 선택된 Property Key(★) → {◆★} 

       ▷ 거래 방식 "동기" 선택 시 → SY
